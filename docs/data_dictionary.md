# Data dictionary

Canonical tables shared by both tracks (`src/glucotwin/schema.py`). Times are timestamps;
inside the pipeline every table also gets `t`, minutes since the participant's first primary
reading. Dates are never compared across participants.

## profiles (one row per participant)

| Column | Meaning | Evidence track | Synthetic track |
|---|---|---|---|
| `pid` | Participant ID | `CGM-0XX` from the file name | `SYN-xxxxxxxx` from the FHIR Patient id |
| `group` | healthy / prediabetes / t2d | derived from HbA1c (<5.7, 5.7–6.4, >6.4 %) | from Synthea conditions |
| `age`, `sex`, `bmi` | Demographics | observed (`bio.csv`) | Synthea (BMI simulated if missing) |
| `hba1c_pct` | HbA1c, % | observed; unit confirmed by the group check | Synthea or simulated (`prov_hba1c_pct`) |
| `fasting_glucose` | mg/dL | observed | Synthea or simulated (`prov_fasting_glucose`) |
| `fasting_insulin` | µU/mL | observed | simulated |
| `triglycerides`, `hdl`, `total_chol`, `ldl`, `vldl` | Lipids, mg/dL | observed (LDL 800 / VLDL 400 set to missing) | Synthea |
| `homa_ir` | fasting insulin × fasting glucose / 405 | derived | derived from synthetic values |
| `tg_hdl` | triglycerides / HDL | derived | derived |
| `primary_coverage` | Dexcom readings present / expected over the wear period | derived | derived |
| `included`, `exclusion_reason` | In the primary analysis (coverage ≥ 70%) | derived | derived |
| `sensor_mard_pct` | Dexcom–Libre mean absolute relative difference | derived | – |
| `conditions`, `metformin`, `insulin_therapy` | From FHIR Condition / MedicationRequest | – | Synthea |
| `tcf7l2_risk_alleles` | Genetic marker, 0–2 | – | simulated, profile only |

## cgm (native sensor readings)

| Column | Meaning |
|---|---|
| `pid`, `time` | Participant and reading time |
| `glucose` | mg/dL as reported (sensor range 40–400, kept raw) |
| `sensor` | `dexcom` (5-minute) or `libre` (15-minute) |
| `censored` | -1 at the floor (≤ 40), +1 at the ceiling (≥ 400), 0 otherwise |

## activity

| Column | Meaning |
|---|---|
| `pid`, `time` | Participant and time (end of the sample) |
| `hr` | Heart rate, bpm |
| `mets` | METs (CGMacros stores METs × 10; divided on load) |
| `dur_min` | Minutes the row covers (1 for CGMacros, 5 for the synthetic track) |

## meals

| Column | Meaning |
|---|---|
| `pid`, `time` | Participant and meal start (CGMacros: photo time) |
| `meal_type` | breakfast / lunch / dinner (/ snack) |
| `carbs`, `protein`, `fat`, `fiber`, `calories` | Logged macros, g (kcal) |
| `fraction` | Proportion eaten (CGMacros "Amount Consumed"; 1.0 if missing, counted) |
| `*_eaten` | Macro × proportion eaten |
| `dish` | Synthetic track only: the Indian meal-library dish |

## sleep

| Column | Meaning |
|---|---|
| `night` | Date of the morning the night ends |
| `sleep_hours` | Evidence: heuristic estimate (`src = derived-heuristic`); synthetic: simulated |
| `coverage` | Share of the 20:00–11:00 window with heart-rate data |
| `available_time` | When the estimate becomes usable (end of the window or wake time) |
| `rmssd` | Nightly HRV, ms; synthetic track only |

## Timeline and prediction moments (built in `features.py`)

| Column | Meaning |
|---|---|
| `src` | `reading` (sensor reading) or `imputed` (gap ≤ 20 min, features only) |
| `status` | `positive`, `negative` or `unscorable` (offline only) |
| `y` | 1, 0 or NaN (unscorable) |
| `cov30` | Readings present / expected in the last 30 minutes (alert rule) |
| features | See APPROACH.md §5.2 |

## Provenance

| Tag | Meaning |
|---|---|
| observed | Measured or logged in the source data, at the sensor's native sampling times |
| derived | Calculated from observed values |
| imputed | Filled in for a missing expected reading; never used to build labels |
| synthetic / simulated | Generated by Synthea or our simulator |
